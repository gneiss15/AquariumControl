# MultiTimer / Dashboard – Raspberry-Pi-Hardware

[English](README.md)

**Coming soon – unvollständige Hardwarebeschreibung.** Der vorhandene Aufbau besteht aus einem Raspberry Pi 3 Model B, einer achtfachen Relaiskarte und einem Netzteil im Gehäuse eines Conrad IR-Powermanagers. MultiTimer und Dashboard laufen als getrennte Dienste auf demselben Pi. Ein zusätzlicher Dienst ist für den Raumtemperatur-Sensor vorgesehen; dessen Einbau und Funktionstest stehen noch aus. Der Akku-Sender läuft auf dem Laptop.
